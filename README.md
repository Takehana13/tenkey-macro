# テンキーマクロ（Mac用）

テンキーなどのホットキーで、記録したマウス・キー操作を再生するアプリです。

## ビルド

```bash
./build.sh
```

ビルドして `/Applications/TenkeyMacro.app` に入れます（`--no-install` を付けると `build/` に作るだけ）。

## 初回設定

システム設定 → プライバシーとセキュリティ → **アクセシビリティ** で「TenkeyMacro」をオンにします。
画面左下が「未許可」のままなら、一覧の TenkeyMacro を「−」で削除し、「＋」で `/Applications/TenkeyMacro.app` を追加し直してください。
署名をアプリID固定にしているので、一度許可すればビルドし直しても許可は残ります。

## 使い方

1. ツールバーの **新規記録** → 売買アプリで操作 → **Esc** で記録停止
2. 右側でホットキー欄をクリック → テンキーを押して割り当て
3. 待機時間（ms）、座標、キーを編集。**一括設定** で全ステップの待機をまとめて短くできる
4. 座標は 🎯 ボタンを押すと、3秒後のマウス位置を取得できる
5. 株数などは「文字入力」ステップで `100` のようにまとめて入力できる（記録時に続けて打った数字も自動でまとめます）

| キー | 動作 |
|---|---|
| 割り当てたキー | マクロ再生（再生中の連打は無視されます） |
| Esc（変更可） | 再生の緊急停止／記録の停止 |
| 切替キー（設定で指定） | ホットキー全体の ON/OFF |

保存先: `~/Library/Application Support/TenkeyMacro/macros.json`（変更すると自動保存）
